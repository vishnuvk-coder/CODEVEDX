# Day 21 – Customer Lifetime Value Analysis

## Project

Sales Data Analysis using SQL

## Objective

The objective of Day 21 was to analyze Customer Lifetime Value (CLV) and identify high-value customers based on their historical purchasing behavior.

## Analysis Performed

### 1. Customer Lifetime Value

Calculated the total revenue generated by each customer.

### 2. Average Order Value

Calculated the average amount spent by customers per order.

### 3. Customer Revenue Ranking

Used SQL Window Functions to rank customers based on lifetime revenue.

### 4. High-Value Customer Analysis

Identified customers whose lifetime value was higher than the average customer lifetime value.

### 5. Customer Value Segmentation

Customers were classified into:

- High Value
- Medium Value
- Low Value

### 6. Overall CLV Summary

Calculated:

- Total Customers
- Total Customer Revenue
- Average Customer Lifetime Value
- Highest Customer Lifetime Value
- Lowest Customer Lifetime Value

This analysis helps businesses:

# 📊 Day 49 — Sales Order Value & Basket Analysis

## Introduction

Day 49 of the **Sales Data Analysis Using SQL** project focuses on **Sales Order Value & Basket Analysis**.

The objective of this analysis is to understand the value of individual customer orders, the average amount generated per order, the number of units purchased per order, and the distribution of orders across different value categories.

This analysis builds on the previous sales KPI and growth analyses and demonstrates how SQL can be used to measure **order-level sales performance and customer basket behavior**.

---

## 🎯 Objectives

The main objectives of Day 49 are:

* Calculate the total number of orders.
* Calculate total sales revenue.
* Calculate revenue generated by each order.
* Calculate Average Order Value (AOV).
* Identify minimum and maximum order values.
* Analyze the number of units included in each order.
* Calculate average units per order.
* Classify orders according to their value.
* Identify high-value orders.
* Analyze order value performance by month.
* Rank orders according to their revenue contribution.
* Create a final order-value and basket-performance summary.

---

---

## 💰 Important Revenue Calculation

The project database does not store the product price directly in `order_items`.

Therefore, order revenue is calculated using:

```sql
oi.quantity * p.price
```

The relationship between the tables is established using:

```sql
orders.order_id = order_items.order_id
```

and:

```sql
order_items.product_id = products.product_id
```

This allows the analysis to calculate the value of each order accurately.

# 📈 Analyses Performed

## 1. Total Number of Orders

The first analysis calculates the total number of unique orders.

```sql
SELECT
    COUNT(DISTINCT o.order_id) AS total_orders
FROM orders o;
```

### Purpose

This provides the overall order volume of the sales dataset.

---

## 2. Total Sales Revenue

The second analysis calculates the total revenue generated from all orders.

```sql
SELECT
    ROUND(SUM(oi.quantity * p.price), 2) AS total_revenue
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id;
```

### Purpose

This provides the overall sales revenue generated by the business.

---

## 3. Revenue Generated by Each Order

Each order's total value is calculated by multiplying the quantity purchased by the product price and aggregating the result for each order.

```sql
SELECT
    o.order_id,
    ROUND(SUM(oi.quantity * p.price), 2) AS order_value
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY o.order_id
ORDER BY order_value DESC;
```

### Purpose

This identifies how much revenue each individual order generated.

---

## 4. Average Order Value

Average Order Value (AOV) measures the average revenue generated per order.

```sql
WITH order_values AS (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_value
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
)

SELECT
    ROUND(AVG(order_value), 2) AS average_order_value
FROM order_values;
```

### Business Meaning

AOV helps businesses understand the typical monetary value of a customer transaction.

---

## 7. Average Units per Order

This analysis measures the average number of units purchased in each order.

```sql
WITH order_units AS (
    SELECT
        o.order_id,
        SUM(oi.quantity) AS total_units
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    GROUP BY o.order_id
)

SELECT
    ROUND(AVG(total_units), 2) AS average_units_per_order
FROM order_units;
```

### Business Meaning

This metric helps measure the typical basket size in terms of product units.

---

## 8. Minimum and Maximum Units per Order

This analysis identifies the smallest and largest number of units purchased in a single order.

```sql
WITH order_units AS (
    SELECT
        o.order_id,
        SUM(oi.quantity) AS total_units
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    GROUP BY o.order_id
)

SELECT
    MIN(total_units) AS minimum_units_per_order,
    MAX(total_units) AS maximum_units_per_order
FROM order_units;
```

### Purpose

This provides a basic understanding of the range of basket sizes.

---

## 9. Order Value Classification

Orders are classified into four categories:

| Order Value    | Category              |
| -------------- | --------------------- |
| Below 500      | Low Value Order       |
| 500–1,999      | Medium Value Order    |
| 2,000–4,999    | High Value Order      |
| 5,000 or above | Very High Value Order |

SQL:

```sql
WITH order_values AS (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_value
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
)

SELECT
    order_id,
    ROUND(order_value, 2) AS order_value,
    CASE
        WHEN order_value < 500 THEN 'Low Value Order'
        WHEN order_value < 2000 THEN 'Medium Value Order'
        WHEN order_value < 5000 THEN 'High Value Order'
        ELSE 'Very High Value Order'
    END AS order_value_category
FROM order_values
ORDER BY order_value DESC;
```

### Purpose

Classification makes it easier to segment orders according to their monetary value.

**Note:** These thresholds are analytical categories defined for this project; they are not database-provided business rules.

## 10. High-Value Order Analysis

Orders with an order value of at least 5,000 are identified.

```sql
WITH order_values AS (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_value
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
)

SELECT
    order_id,
    ROUND(order_value, 2) AS order_value
FROM order_values
WHERE order_value >= 5000
ORDER BY order_value DESC;
```

### Business Meaning

This analysis helps identify orders that generate relatively large amounts of revenue.

---

## 11. Monthly Order Value Analysis

Order value and Average Order Value are analyzed by month.

```sql
SELECT
    DATE_FORMAT(o.order_date, '%Y-%m') AS sales_month,
    COUNT(DISTINCT o.order_id) AS total_orders,
    ROUND(SUM(oi.quantity * p.price), 2) AS total_revenue,
    ROUND(
        SUM(oi.quantity * p.price)
        / COUNT(DISTINCT o.order_id),
        2
    ) AS average_order_value
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY DATE_FORMAT(o.order_date, '%Y-%m')
ORDER BY sales_month;
```

### Purpose

This analysis allows the business to compare:

* Monthly order volume
* Monthly revenue
* Monthly Average Order Value

It can help identify changes in customer purchasing behavior over time.

---

## 12. Order Value Ranking

Orders are ranked according to their total revenue.

```sql
WITH order_values AS (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_value
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
)

SELECT
    order_id,
    ROUND(order_value, 2) AS order_value,
    RANK() OVER (
        ORDER BY order_value DESC
    ) AS order_value_rank
FROM order_values
ORDER BY order_value_rank;
```

### SQL Concepts Demonstrated

This query demonstrates the use of the **RANK() window function** to order transactions according to their revenue.

# 13. Final Order Value & Basket Summary

The final query combines the main order-value metrics.

```sql
WITH order_summary AS (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_value,
        SUM(oi.quantity) AS total_units
    FROM orders o
    JOIN order_items oi
        ON o.order_id = oi.order_id
    JOIN products p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
)

SELECT
    COUNT(*) AS total_orders,
    ROUND(SUM(order_value), 2) AS total_revenue,
    ROUND(AVG(order_value), 2) AS average_order_value,
    ROUND(MIN(order_value), 2) AS minimum_order_value,
    ROUND(MAX(order_value), 2) AS maximum_order_value,
    ROUND(AVG(total_units), 2) AS average_units_per_order,
    MIN(total_units) AS minimum_units_per_order,
    MAX(total_units) AS maximum_units_per_order
FROM order_summary;
```

### Purpose

This provides a consolidated view of the main order-value and basket metrics.

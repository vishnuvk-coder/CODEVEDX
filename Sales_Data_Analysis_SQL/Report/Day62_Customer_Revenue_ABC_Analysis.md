# 📊 Day 62 — Customer Revenue ABC Classification Analysis

Day 62 focused on Customer Revenue ABC Classification Analysis using MySQL.

The analysis extends the customer revenue distribution and concentration work completed in previous days by classifying customers into A, B, and C revenue groups based on cumulative revenue contribution.

---

## 🎯 Day 62 Objective

The objective was to classify customers according to their contribution to total customer revenue.

The analysis answers questions such as:

- Which customers contribute the largest share of revenue?
- Which customers belong to Class A?
- Which customers belong to Class B?
- Which customers belong to Class C?
- What percentage of customers belong to each class?
- How much revenue does each class generate?
- How many orders and units are generated by each class?
- What is the average revenue per customer in each class?
- How is revenue distributed across ABC customer groups?

## 📊 ABC Classification

Customers are classified according to their cumulative contribution to total revenue.

| Class | Cumulative Revenue | Description |
|---|---:|---|
| A | Up to 80% | Highest revenue contribution |
| B | 80%–95% | Medium revenue contribution |
| C | Above 95% | Lower revenue contribution |

These thresholds are business-analysis rules used for this portfolio project.

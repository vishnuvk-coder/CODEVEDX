**Sales Data Analysis Using SQL**

**Day:** 29

**Topic:** Customer Purchase Frequency & Order Value Analysis

**Database:** MySQL 8.0

## 🎯 Objective

The objective of Day 29 is to analyze customer purchasing frequency and order value.

The analysis measures how frequently customers place orders, how much they spend, their average order value, and their overall purchasing behavior.

The analysis also identifies high-frequency and high-value customers using SQL-based customer segmentation.

## 🔍 Analysis Performed

### 1. Customer Order Frequency

Calculated the total number of orders placed by each customer.

### 2. Average Order Value

Calculated the average amount spent per order for each customer.

### 3. Customer Total Spending

Measured the total revenue generated by each customer.

### 4. Purchase Frequency Classification

Customers were classified into:

- Very Frequent
- Frequent
- Repeat
- One-Time

### 5. Order Value Classification

Orders were classified into:

- High Value Order
- Medium Value Order
- Low Value Order

### 6. Customer Ranking

Customers were ranked according to their purchase frequency using the `RANK()` window function.

### 7. Frequency Contribution

Measured each customer's contribution to the overall number of orders.

### 8. Customer Profile Analysis

Customers were classified according to both purchase frequency and revenue.

The analysis identifies:

- High Frequency - High Value
- High Frequency - Lower Value
- Low Frequency - High Value
- Standard Customer

### 9. Customer Purchase Behavior Report

Created a combined business report containing:

- Total orders
- Total revenue
- Average order value
- Purchase frequency rank
- Customer segment

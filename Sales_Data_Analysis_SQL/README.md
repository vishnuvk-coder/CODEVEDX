| 4–6 orders        | Regular Repeat Customer    |
| 7+ orders         | Highly Loyal Customer      |

## Day 52 Prediction Categories

| Prediction                         | Description                                    |
| ---------------------------------- | ---------------------------------------------- |
| High Repeat Purchase Potential     | 4+ orders and recent activity                  |
| Moderate Repeat Purchase Potential | Multiple orders and relatively recent activity |
| At-Risk Repeat Customer            | Repeat customer with older activity            |
| Potential New Repeat Customer      | One order with relatively recent activity      |
| Low Repeat Purchase Potential      | One order with older activity                  |

These are **business-analysis rules**, not machine-learning predictions.

# 🗄️ Database Design

The project uses five primary tables:

| Table         | Description                        |
| ------------- | ---------------------------------- |
| `customers`   | Stores customer information        |
| `products`    | Stores product details and pricing |
| `orders`      | Stores customer order records      |
| `order_items` | Stores products included in orders |
| `payments`    | Stores payment information         |

### Database Relationships

```text
Customers
   │
   └── Orders
          │
          ├── Order_Items ─── Products
          │
          └── Payments
```

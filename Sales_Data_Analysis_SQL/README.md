# 🗄️ Database Design

The project uses a relational sales database consisting of five primary tables.

| Table         | Description                        |
| ------------- | ---------------------------------- |
| `Customers`   | Stores customer information        |
| `Products`    | Stores product details and pricing |
| `Orders`      | Stores customer order records      |
| `Order_Items` | Stores products included in orders |
| `Payments`    | Stores payment information         |

## 🔗 Database Relationships

```text
Customers
   │
   └── Orders
          │
          ├── Order_Items ─── Products
          │
          └── Payments
```

# 🚀 Day 37 Achievement

## Day 37 — Customer RFM Segmentation Analysis Completed ✅

Day 37 has been successfully completed as part of the structured SQL business-analysis journey.

The Day 37 analysis focuses on **Customer RFM Segmentation**, a widely used customer analytics framework based on three dimensions:

* **Recency** — How recently a customer made a purchase.
* **Frequency** — How often a customer places orders.
* **Monetary Value** — How much revenue a customer generates.

The analysis includes:

* Customer Recency
* Customer Frequency
* Customer Monetary Value
* Complete Customer RFM Metrics
* Recency Score
* Frequency Score
* Monetary Score
* Complete RFM Score
* Customer RFM Segmentation
* Champion Customer Identification
* At-Risk Customer Identification
* Final RFM Business Summary

The customer scoring process uses **NTILE(5)** to divide customers into five scoring groups.

Customers are then classified into business segments such as:

* **Champions**
* **Loyal Customers**
* **New Customers**
* **At-Risk Customers**
* **Lost Customers**
* **Potential Customers**

The analysis applies advanced SQL techniques including:

* Aggregate functions
* JOINs
* GROUP BY
* CTEs
* Window Functions
* NTILE()
* COUNT()
* SUM()
* MAX()
* MIN()
* DATEDIFF()
* CASE statements
* Subqueries
* Customer-level aggregation
* RFM scoring
* Customer segmentation

The RFM analysis helps transform customer transaction history into actionable customer segments.
